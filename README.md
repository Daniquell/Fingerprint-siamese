# Fingerprint-siamese
Siamese Network for fingerprint verification
> **Сиамская нейросеть для биометрической аутентификации по отпечаткам пальцев**  
> — Реализовал архитектуру Siamese Network для сравнения двух отпечатков.  
> — Обучил модель на датасете FVC2000 DB4-B (фрагмент).  
> — Достиг **точности 99.8%** на обучающих парах.  
> — Реализовал функцию для практического сравнения отпечатков.  
> **Технологии:** Python, TensorFlow, Keras
