# Fingerprint-siamese
Siamese Network for fingerprint verification
> **Siamese Neural Network for Fingerprint-Based Biometric Authentication**  
— A Siamese neural network architecture was implemented for the pairwise comparison of fingerprint images. 
— The model was trained on a subset of the FVC2000 DB4-B dataset.
— An accuracy of **99.8%** was achieved on the training pairs.
— A dedicated function was developed for practical fingerprint matching and verification.
> **Technologies:** Python, TensorFlow, Keras
